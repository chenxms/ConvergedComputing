## 3. P0 高收益性能优化（当天落地）

目标：消除“逐维度循环 + 频繁 JSON_EXTRACT + 重复回表”的线性放大；避免无谓 COLLATE/CAST 触发索引失效。

### 3.1 集合化 SQL：区域维度均分（已完成）
- 位置：`app/services/subjects_builder.py:_compute_regional_dimension_avgs`
- 调整：用单条查询产出“全部维度 → AVG(score)”映射，参考 `build_dimension_rank_cache` 的 CTE 结构；去除冗余 COLLATE/CAST。

SQL 模板：
```
WITH dim_list AS (
  SELECT DISTINCT dimension_code FROM batch_dimension_definition WHERE batch_code=:batch AND subject_name=:subject
  UNION
  SELECT DISTINCT dimension_code FROM question_dimension_mapping WHERE batch_code=:batch AND subject_name=:subject
), per_row AS (
  SELECT dl.dimension_code,
         CAST(JSON_UNQUOTE(JSON_EXTRACT(CAST(scs.dimension_scores AS JSON), CONCAT('$."', dl.dimension_code, '".score'))) AS DECIMAL(10,4)) AS dim_score
  FROM student_cleaned_scores scs
  JOIN school_master_data smd ON smd.batch_code=scs.batch_code AND smd.school_id=scs.school_code AND smd.status='ACTIVE'
  JOIN dim_list dl
  WHERE scs.batch_code=:batch AND scs.subject_name=:subject AND scs.subject_type IN ('exam','questionnaire')
), per_row_q AS (
  SELECT qdm.dimension_code, qqs.original_score AS dim_score
  FROM questionnaire_question_scores qqs
  JOIN question_dimension_mapping qdm ON qdm.batch_code=qqs.batch_code AND qdm.question_id=qqs.question_id AND qdm.subject_name=:subject
  JOIN school_master_data smd ON smd.batch_code=qqs.batch_code AND smd.school_id=qqs.school_id AND smd.status='ACTIVE'
  WHERE qqs.batch_code=:batch AND qqs.subject_name=:subject
), unioned AS (
  SELECT dimension_code, dim_score FROM per_row WHERE dim_score IS NOT NULL
  UNION ALL
  SELECT dimension_code, dim_score FROM per_row_q
)
SELECT dimension_code, ROUND(AVG(dim_score), 2) AS dim_avg FROM unioned GROUP BY dimension_code;
```

## 7. 运维注意与常见场景

- 何时需要“建索引”
  - 同一 MySQL 实例/表未重建：不需要每次执行，之前创建的索引持续生效。
  - 新实例/表重建/大规模导入后：建议执行 `python add_performance_indexes.py` 自检并补齐。

- 何时需要设置写入开关（DISABLE_WRITES_FOR_BATCHES）
  - 容器环境：使用 `docker-compose.utf8.yml` 启动后默认允许写入，无需每次设置。
  - 本机直接跑脚本：如需临时放开，当前 PowerShell 会话可执行 `$env:DISABLE_WRITES_FOR_BATCHES = ''`。
  - 检查容器变量：`docker exec converged-computing-app env | grep DISABLE_WRITES_FOR_BATCHES || echo not_set`

- 问卷标签/分布为空的处理
  - 先运行：`python scripts/complete_questionnaire_labels.py G7-2025`
  - 再重建区域（含 detail）：`python scripts/rebuild_regional_v12.py --batch G7-2025 --include-detail`

- 常见执行选择
  - 首次全量（区域+学校，含缓存）：`docker exec converged-computing-app python -u -c "import sys; sys.path.insert(0,'/app'); from scripts.rewrite_subjects_v12 import rewrite_batch; rewrite_batch('G7-2025')"`
  - 仅区域（带 detail 兼容旧端）：`docker exec converged-computing-app python -u /app/scripts/rebuild_regional_v12.py --batch G7-2025 --include-detail`
  - 仅学校修复：`docker exec converged-computing-app python -u /app/scripts/rebuild_school_v12.py G7-2025`
  - API 触发区域：`curl "http://localhost:8011/api/v12/batch/G7-2025/regional?include_detail=true"`
  - API 全量物化：`curl -X POST "http://localhost:8011/api/v12/batch/G7-2025/materialize"`

- 快速验收清单
  - `statistical_aggregations` 中 REGIONAL/SCHOOL 记录存在且 `statistics_data.data_version == 'v1.2'`。
  - 抽查考试与问卷科目：`metrics.student_count/score_rate/percentiles/discrimination` 齐全，问卷维度含 `avg/score_rate`。
  - EXPLAIN 集合化查询无全表扫描，关键索引命中（用 `scripts/explain_regional_dimension_queries.py` 验证）。
