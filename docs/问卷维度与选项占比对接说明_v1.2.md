# 问卷维度平均与题目选项占比对接说明（v1.2）

适用范围：前端在呈现问卷类科目时，需要“按维度”展示维度平均分，以及维度下各题目的选项占比（百分比 0–100）。本文基于当前后端实现整理了最简对接路径。

---

## 一、相关接口概览

- Subjects v1.2（维度平均、排名等聚合数据）
  - 区域级：`GET /api/v12/batch/{batch_code}/regional`
  - 学校级：`GET /api/v12/batch/{batch_code}/school/{school_id}`

- 问卷题目选项分布（题目级百分比，不内嵌在 subjects）
  - 区域级：`GET /api/v1/questionnaire-distributions/{batch_code}/{subject_name}/regional`
  - 学校级：`GET /api/v1/questionnaire-distributions/{batch_code}/{subject_name}/school/{school_id}`
  - 列出有问卷数据的学校：`GET /api/v1/questionnaire-distributions/{batch_code}/{subject_name}/schools`

说明：
- 学校级维度平均/排名等请走 v1.2 subjects；题目选项分布请走 questionnaire-distributions v1。
- 题目归属哪个维度由静态映射决定（不随学校变化），可用“区域级 subjects”中维度下的题目清单作为映射来源。

---

## 二、区域级（REGIONAL）：按维度一把抓

一次请求获取“维度平均 + 维度下题目选项分布（已归组）”。

1) 拉取区域级 subjects：

```
GET /api/v12/batch/{batch_code}/regional
```

2) 在返回的 `data.subjects[]` 中找到问卷科目（`type === 'questionnaire'` 或按科目名匹配），读取：

- 维度平均：`dimensions[].avg`
- 维度下题目选项分布：`dimensions[].questions[]`，每题包含：
  - `question_id`
  - `option_distribution`: `[ { option_level, option_label, pct } ]`（`pct` 为 0–100）

结构示例（片段）：

```json
{
  "subject_name": "问卷",
  "type": "questionnaire",
  "dimensions": [
    {
      "code": "D-CUR",
      "name": "好奇心",
      "avg": 82.35,
      "questions": [
        {
          "question_id": "Q01",
          "option_distribution": [
            { "option_level": 1, "option_label": "非常不符合", "pct": 5.21 },
            { "option_level": 2, "option_label": "不符合",     "pct": 12.45 },
            { "option_level": 3, "option_label": "一般",       "pct": 30.29 },
            { "option_level": 4, "option_label": "符合",       "pct": 36.10 },
            { "option_level": 5, "option_label": "非常符合",   "pct": 15.95 }
          ]
        }
      ]
    }
  ]
}
```

## 三、学校级（SCHOOL）：聚合 + 题目分布 + 映射归组

学校级需要两次请求：

1) 维度聚合（平均/得分率/名次）

```
GET /api/v12/batch/{batch_code}/school/{school_id}
```

读取问卷科目下 `dimensions[]`：

- `avg`：维度平均分
- `score_rate`：维度得分率（0–100）
- `rank`：维度区域内名次（DENSE_RANK）

2) 题目选项分布（学校级）

```
GET /api/v1/questionnaire-distributions/{batch_code}/{subject_name}/school/{school_id}
```

返回 `data.questions[]`：

- `question_id`
- `total_responses`
- `options`: `[ { option_level, option_label, pct } ]`（`pct` 为 0–100）

3) 题目→维度归组（前端在内存中完成）

- 从“区域级 subjects”构建一次 `question_id -> dimension_code` 映射并缓存（按 `batch+subject` 维度存放）。
- 将步骤 2 的 `questions[]` 用该映射归组到各维度下渲染。

示例伪代码：

```ts
// 1) 区域级映射
const regional = await fetch(`${BASE}/api/v12/batch/${batch}/regional`).then(r => r.json());
const qSubj = regional.data.subjects.find((s: any) => s.type === 'questionnaire' && s.subject_name === subject);
const qid2dim = new Map<string, string>();
for (const dim of qSubj.dimensions || []) {
  for (const q of dim.questions || []) qid2dim.set(q.question_id, dim.code);
}

// 2) 学校级题目分布
const dist = await fetch(`${BASE}/api/v1/questionnaire-distributions/${batch}/${subject}/school/${schoolId}`).then(r => r.json());
const byDim: Record<string, any[]> = {};
for (const q of dist.data.questions || []) {
  const dim = qid2dim.get(q.question_id) || 'UNMAPPED';
  (byDim[dim] ||= []).push(q);
}
```

## 四、对接注意事项

- 百分比字段说明：
  - subjects v1.2 中的分布使用 `pct`，问卷分布 v1 API 也返回 `pct`；个别聚合接口可能返回 `percentage`，语义一致，均为 0–100。
- 选项标签缺失：若 `option_label` 为空，请回退 `选项{option_level}`。
- 维度名称：如未配置，将回退为 `code`；学校级同时提供 `score_rate` 与 `rank` 以便对比与排序。
- 缓存建议：题目→维度映射可按 `batch+subject` 缓存，减少地域/学校切换时的额外请求。
