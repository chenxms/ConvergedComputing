**背景与目标**
- 现有 API 无鉴权，存在数据泄露与越权风险。
- 目标：在 FastAPI 中引入“认证 + 鉴权（RBAC/权限点）”，与前端权限标识对齐（如 `system:results:list`），并兼容未来接入网关/SSO。

**总体方案**
- 认证：JWT（`Authorization: Bearer <token>`）。可先自签，后续切换为网关/SSO 签发。
- 鉴权：RBAC + 细粒度权限点（字符串），如 `system:results:list`、`system:results:write`、`system:tasks:run`。
- 集成方式：FastAPI 依赖项统一校验，路由上声明 `require_permissions(...)` 与可选 ABAC（学校数据隔离）。
- 兼容性：支持网关透传 JWT 或用户头（`X-User`/`X-Perms`）适配；提供观测模式 `AUTH_DISABLED=true` 先行上线。

**权限模型**
- 实体：`users`、`roles`、`permissions`、`user_roles`、`role_permissions`（或对接外部 IAM）。
- 权限点命名：沿用前端风格 `system:模块:动作`，前后端同源，避免命名漂移。
- 令牌中拍扁权限：登录后把用户最终权限列表放入 JWT 的 `perms`，减少请求期 DB 查表与不一致风险。
- 学校/组织隔离（可选 ABAC）：在 `school_ids` 或 `org_id` 维度上限制访问范围。

**JWT 载荷建议**
- 必要字段：`sub`（用户ID）、`name`、`roles`（字符串数组）、`perms`（字符串数组）、`iat`、`exp`、`iss`、`aud`。
- 数据隔离：`school_ids`（字符串数组）或 `org_id`。
- 管理标识：`is_admin`（跳过权限检查但仍记录审计日志）。
- 秘钥管理：`kid` 以支持多秘钥轮换；生产通过环境变量或密钥管理系统注入。

**接口-权限映射（建议）**
- 只读（READ）：`system:results:list`
  - `GET /api/v12/batch/{batch_code}/regional`
  - `GET /api/v12/batch/{batch_code}/school/{school_id}`（叠加学校访问约束）
  - 问卷分布查询：`GET /api/v1/questionnaire-distributions/...`
- 写入/任务（WRITE/TASK）：`system:results:write` 或 `system:tasks:run`
  - `POST /api/v12/batch/{batch_code}/materialize`
  - `POST /api/v1/questionnaire-distributions/{batch_code}/{subject}/populate`
  - `DELETE /api/v1/questionnaire-distributions/{batch_code}`
  - 统计/清洗任务管理：`/api/v1/statistics/tasks/*`
- 公开：`GET /`、`GET /health`（生产建议经网关白名单控制或也加最小权限）。

**FastAPI 集成设计**
- 新增模块：`app/auth/security.py`
  - 环境变量：
    - `JWT_SECRET`（默认 dev）、`JWT_ALG=HS256`、`ACCESS_TOKEN_EXPIRE_MINUTES`（可选）
    - `AUTH_DISABLED`（`true|false`，观测模式，仅告警不阻断）
  - 方法与依赖：
    - `get_current_user`：解码校验 JWT，构造 `CurrentUser`（`user_id`、`roles`、`perms`、`school_ids`、`is_admin`）。
    - `require_permissions(*perms)`：RBAC 校验（`403` 返回缺失权限清单）。
    - `require_school_access(param="school_id")`：ABAC 校验，限制学校访问范围。
  - 网关适配（可选）：若存在 `X-User`/`X-Perms`/`X-School-Ids`，可直接构造 `CurrentUser`，跳过本地解码。

示例（简化示意，供落地用）：
```
from fastapi import Depends, HTTPException, Request, status
from fastapi.security import OAuth2PasswordBearer
import os, time, jwt
from pydantic import BaseModel

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/auth/login", auto_error=True)
JWT_SECRET = os.getenv("JWT_SECRET", "dev-secret")
JWT_ALG = os.getenv("JWT_ALG", "HS256")
AUTH_DISABLED = os.getenv("AUTH_DISABLED", "false").lower() == "true"

class CurrentUser(BaseModel):
    user_id: str
    name: str | None = None
    roles: list[str] = []
    perms: set[str] = set()
    school_ids: set[str] = set()
    is_admin: bool = False

def decode_token(token: str) -> CurrentUser:
    payload = jwt.decode(token, JWT_SECRET, algorithms=[JWT_ALG], options={"verify_aud": False})
    if "exp" in payload and payload["exp"] < time.time():
        raise HTTPException(status_code=401, detail="Token已过期")
    return CurrentUser(
        user_id=str(payload.get("sub")),
        name=payload.get("name"),
        roles=payload.get("roles", []) or [],
        perms=set(payload.get("perms", []) or []),
        school_ids=set(payload.get("school_ids", []) or []),
        is_admin=bool(payload.get("is_admin", False)),
    )

def get_current_user(token: str = Depends(oauth2_scheme)) -> CurrentUser:
    try:
        return decode_token(token)
    except jwt.PyJWTError as e:
        if AUTH_DISABLED:
            return CurrentUser(user_id="anonymous")
        raise HTTPException(status_code=401, detail=f"认证失败: {e}")

def require_permissions(*needed: str):
    def checker(user: CurrentUser = Depends(get_current_user)):
        if AUTH_DISABLED or user.is_admin:
            return
        missing = [p for p in needed if p not in user.perms]
        if missing:
            raise HTTPException(
                status_code=403,
                detail={"message": "权限不足", "required": list(needed), "owned": list(user.perms)}
            )
    return checker

def require_school_access(param_name: str = "school_id"):
    def checker(request: Request, user: CurrentUser = Depends(get_current_user)):
        if AUTH_DISABLED or user.is_admin or "regional" in user.roles:
            return
        sid = request.path_params.get(param_name)
        if sid and sid not in user.school_ids:
            raise HTTPException(status_code=403, detail="无权访问该学校数据")
    return checker
```

**在路由中接入（示例）**
- subjects v1.2（只读）
  - `app/api/subjects_v12_api.py`
  - 只读整体：`router = APIRouter(dependencies=[Depends(require_permissions("system:results:list"))])`
  - 学校级再加 ABAC：`@router.get(..., dependencies=[Depends(require_school_access())])`
- 物化/写入类（写权限）：
  - `@router.post(..., dependencies=[Depends(require_permissions("system:results:write"))])`
- 问卷分布：
  - `GET ...` 用 `system:results:list`；`POST/DELETE ...` 用 `system:results:write`。

注意：生产建议对除 `/`、`/health` 外的路由均加依赖；也可在 `app/main.py` 用全局 `dependencies` 挂在某些 Router 上，写接口单独覆盖。

**网关/SSO 对接策略**
- 优先网关/SSO（Keycloak/企业OAuth2/Nginx auth_request）签发或透传 JWT：后端只需验证签名与 `exp/iss/aud`，并做权限点校验。
- 网关转发用户头：在 `security.py` 中优先读取 `X-User`（JSON/ID）、`X-Perms`（逗号分隔/JSON 数组）、`X-School-Ids`，直接构造 `CurrentUser`。
- 多秘钥轮换：使用 `kid` 与 JWKS；或本地维护 `JWT_SECRETS_JSON`，按 `kid` 查找秘钥验证。

**生产加固**
- CORS：`allow_origins` 设为业务域名白名单；`allow_credentials=True`。
- 文档：外网关闭 `/docs`、`/redoc` 或加权限保护。
- 审计与限流：日志记录 `user_id`、`route`、`school_id`、`ip`、`result`；网关层限流与 WAF。
- HTTP 语义：认证失败 `401`；权限不足 `403`；参数错误 `400`；服务异常 `500`。
- 秘钥：`JWT_SECRET` 不落盘；使用环境变量/密钥管理系统；定期轮换。

**实施步骤（建议）**
1) 引入 `app/auth/security.py`；在 subjects、问卷“只读”接口加 `system:results:list`；学校级接口加 `require_school_access()`；开启 `AUTH_DISABLED=true` 观测。
2) 为写入/任务接口加 `system:results:write` 或 `system:tasks:run`；整理“路由-权限点映射”表，前后端对齐。
3) 前端统一携带 `Authorization: Bearer <token>`；后端切换 `AUTH_DISABLED=false` 强制执行。
4) 生产环境：CORS 白名单、关闭文档、开启审计/限流；必要时切换为网关/SSO 签发 JWT。

**需要确认的决策**
- 是否已有网关/SSO（JWT 标准/头部格式），以便我们按其格式适配？
- 是否启用学校级数据隔离（ABAC）作为强制策略？
- 是否接受新增权限点：`system:results:write`、`system:tasks:run`？如接受，我会出全量路由-权限对照表。

**环境变量清单（示例）**
- `JWT_SECRET`：JWT 签名秘钥（开发可临时使用默认，生产必须注入）。
- `JWT_ALG`：默认 `HS256`；如接入 SSO 可为 `RS256`（需配公钥）。
- `AUTH_DISABLED`：`true|false`，观测模式仅日志告警，不阻断请求。
- `ACCESS_TOKEN_EXPIRE_MINUTES`：令牌有效期（可选）。
