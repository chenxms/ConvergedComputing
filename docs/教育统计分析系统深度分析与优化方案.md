# 教育统计分析系统深度分析与优化方案

## 执行摘要

本文档对教育统计分析系统进行了全面深度分析，识别出多项关键缺陷和改进点。主要问题集中在统计指标缺失、数据清洗缺陷、满分计算不一致等方面。本方案提供了详细的问题分析和具体的优化实施路径。

## 二、核心问题清单

### 2.1 统计指标缺失

#### 问题1：区分度指标缺失
- **现状**：系统未在最终输出中包含区分度指标
- **影响**：无法评估题目质量和学生能力区分效果
- **公式**：`区分度 = (前27%平均分 - 后27%平均分) / 满分`

#### 问题2：百分位数未输出
- **现状**：虽然计算了P10、P50、P90，但未在最终JSON中输出
- **影响**：前端无法展示学生分数分布情况
- **需求**：
  - P10：10%位置学生的分数
  - P50：中位数
  - P90：90%位置学生的分数

#### 问题3：等级占比统计缺失
- **现状**：系统未提供优秀、良好、及格、不及格的占比数据
- **影响**：无法快速了解整体成绩分布
- **标准**：
  - 小学(1-6年级)：优秀≥85, 良好70-84, 及格60-69, 不及格<60
  - 初中(7-9年级)：A≥80, B70-79, C60-69, D<60

#### 3.2.1 实现区分度计算

```python
# app/services/calculation_service.py 增强
def _calculate_discrimination(self, data: pd.DataFrame, max_score: float) -> Dict:
    """计算区分度指标"""
    if len(data) < 30:  # 样本量要求
        return {"value": None, "message": "样本量不足"}
    
    sorted_data = data.sort_values('score', ascending=False)
    n = len(sorted_data)
    top_27_count = int(n * 0.27)
    bottom_27_count = int(n * 0.27)
    
    top_27_mean = sorted_data.iloc[:top_27_count]['score'].mean()
    bottom_27_mean = sorted_data.iloc[-bottom_27_count:]['score'].mean()
    
    discrimination = (top_27_mean - bottom_27_mean) / max_score
    
    return {
        "value": round(discrimination, 4),
        "top_27_mean": round(top_27_mean, 2),
        "bottom_27_mean": round(bottom_27_mean, 2),
        "interpretation": self._interpret_discrimination(discrimination)
    }

def _interpret_discrimination(self, value: float) -> str:
    """解释区分度值"""
    if value >= 0.4:
        return "优秀"
    elif value >= 0.3:
        return "良好"
    elif value >= 0.2:
        return "尚可"
    else:
        return "需改进"
```

```python
# app/services/calculation_service.py 新增
def _calculate_grade_distribution(self, data: pd.DataFrame, grade: int) -> Dict:
    """计算等级分布占比"""
    total = len(data)
    if total == 0:
        return {}
    
    if grade <= 6:  # 小学
        excellent = len(data[data['score'] >= 85]) / total * 100
        good = len(data[(data['score'] >= 70) & (data['score'] < 85)]) / total * 100
        pass_rate = len(data[(data['score'] >= 60) & (data['score'] < 70)]) / total * 100
        fail = len(data[data['score'] < 60]) / total * 100
        
        return {
            "excellent": round(excellent, 2),
            "good": round(good, 2),
            "pass": round(pass_rate, 2),
            "fail": round(fail, 2),
            "labels": ["优秀", "良好", "及格", "不及格"]
        }
    else:  # 初中
        grade_a = len(data[data['score'] >= 80]) / total * 100
        grade_b = len(data[(data['score'] >= 70) & (data['score'] < 80)]) / total * 100
        grade_c = len(data[(data['score'] >= 60) & (data['score'] < 70)]) / total * 100
        grade_d = len(data[data['score'] < 60]) / total * 100
        
        return {
            "A": round(grade_a, 2),
            "B": round(grade_b, 2),
            "C": round(grade_c, 2),
            "D": round(grade_d, 2),
            "labels": ["A等", "B等", "C等", "D等"]
        }
```

```python
async def _get_subject_max_score(self, batch_code: str, subject_name: str) -> float:
    """统一从配置表获取科目满分"""
    query = """
    SELECT SUM(max_score) as total_max_score
    FROM subject_question_config

    """
```
