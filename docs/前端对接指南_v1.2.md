# v1.2 API前端对接完整指南

## 概述

本指南为前端开发团队提供 v1.2 统计分析API的完整对接方案。v1.2版本统一了考试和问卷数据结构，提供更清晰的数据格式和更丰富的统计信息。

### 版本特性
- 🔄 统一数据结构：考试与问卷数据统一为 `subjects` 数组
- 📊 完整排名信息：区域排名、学校排名、维度排名
- 📈 精确数值格式：统一两位小数，百分比0-100范围
- 🏷️ 问卷标签支持：完整的选项分布和标签映射
- 📱 前端友好：优化的JSON结构，便于数据绑定

## 1. 快速开始

### 1.1 API基础信息
- **基础URL**: `http://your-domain:8000`
- **版本标识**: `v1.2`
- **内容类型**: `application/json; charset=utf-8`
- **编码**: UTF-8（支持中文字符）

### 1.2 认证方式
当前版本暂无认证要求，生产环境请根据实际情况添加认证头。

### 1.3 响应格式
所有API响应遵循统一格式：
```json
{
  "success": true|false,
  "message": "操作结果描述",
  "data": { ... },
  "code": 200
}
```

### 1.4 错误处理
```javascript
const handleApiResponse = async (response) => {
  if (!response.ok) {
    throw new Error(`API Error: ${response.status}`);
  }
  
  const result = await response.json();
  
  if (!result.success) {
    throw new Error(result.message || '请求失败');
  }
  
  return result.data;
};
```

### 2.3 批次物化API

#### 端点
```
POST /api/v12/batch/{batch_code}/materialize
```

#### 功能描述
为指定批次预生成所有学校的统计数据，适用于批次上线前的数据预处理。

#### 使用场景
- 批次数据初次发布前
- 定期数据刷新任务
- 系统维护后的数据重建

#### 请求示例
```javascript
const materializeBatch = async (batchCode) => {
  const response = await fetch(
    `/api/v12/batch/${batchCode}/materialize`,
    { method: 'POST' }
  );
  return handleApiResponse(response);
};

// 带进度显示的处理
const handleMaterialize = async (batchCode) => {
  try {
    showLoading('正在生成统计数据...');
    const result = await materializeBatch(batchCode);
    showSuccess(`成功生成 ${result.schools_materialized} 所学校的数据`);
  } catch (error) {
    showError(`生成失败: ${error.message}`);
  } finally {
    hideLoading();
  }
};
```

#### 注意事项
- 该操作耗时较长，建议显示进度提示
- 大批次数据可能需要几分钟时间
- 建议在低峰时段执行

## 3. 数据结构深度解析

### 3.1 subjects数组结构

#### 考试类科目 (type: "exam")
```typescript
interface ExamSubject {
  subject_name: string;           // 科目名称
  type: "exam";                   // 固定值
  metrics: {
    avg: number;                  // 平均分 (两位小数)
    stddev: number;               // 标准差 (两位小数)
    max: number;                  // 最高分 (两位小数)
    min: number;                  // 最低分 (两位小数)
    difficulty: number;           // 难度系数 (0-1, 两位小数)
  };
  // 区域层特有
  school_rankings?: SchoolRanking[];
  // 学校层特有  
  region_rank?: number;           // 区域排名
  total_schools?: number;         // 参与学校数
  dimensions: ExamDimension[];    // 维度数据
}
```

#### 问卷类科目 (type: "questionnaire")
```typescript
interface QuestionnaireSubject {
  subject_name: string;           // 问卷名称
  type: "questionnaire";          // 固定值
  metrics: {
    avg: number;                  // 平均分 (两位小数)
    stddev: number;               // 标准差 (两位小数)  
    max: number;                  // 最高分 (两位小数)
    min: number;                  // 最低分 (两位小数)

  };
  // 区域层特有
  school_rankings?: SchoolRanking[];
  // 学校层特有
```

### 3.2 问卷数据特殊处理

#### 选项分布结构
```typescript
interface OptionDistribution {
  option_level: number;           // 选项等级 (1-5 或 1-10)
  option_label?: string;          // 选项标签 (可选)
  pct: number;                    // 百分比 (0-100, 两位小数)
}
```

#### 问卷维度处理
```javascript
// 渲染问卷满意度分布
const renderSatisfactionChart = (optionDistribution) => {
  const chartData = optionDistribution.map(option => ({
    name: option.option_label || `选项${option.option_level}`,
    value: option.pct,
    level: option.option_level
  }));
  
  // 按选项等级排序
  chartData.sort((a, b) => b.level - a.level);
  
  return chartData;
};

// 计算满意度汇总
const calculateSatisfactionSummary = (optionDistribution) => {
  const satisfied = optionDistribution
    .filter(opt => opt.option_level >= 4)  // 满意及以上
    .reduce((sum, opt) => sum + opt.pct, 0);
    
  const neutral = optionDistribution
    .filter(opt => opt.option_level === 3)  // 一般
    .reduce((sum, opt) => sum + opt.pct, 0);
    
  const dissatisfied = optionDistribution
    .filter(opt => opt.option_level <= 2)  // 不满意及以下
    .reduce((sum, opt) => sum + opt.pct, 0);
    
  return { satisfied, neutral, dissatisfied };
};
```

#### 10级量表处理建议
```javascript
// 10级量表转换为5级显示
const convert10To5Scale = (optionDistribution) => {
  const mapping = {
    1: 1, 2: 1,    // 1-2 -> 1 (很不满意)
    3: 2, 4: 2,    // 3-4 -> 2 (不满意)  
    5: 3, 6: 3,    // 5-6 -> 3 (一般)
    7: 4, 8: 4,    // 7-8 -> 4 (满意)
    9: 5, 10: 5    // 9-10 -> 5 (很满意)
  };
  
  const result = {};
  optionDistribution.forEach(opt => {
    const mappedLevel = mapping[opt.option_level];
    if (!result[mappedLevel]) {
      result[mappedLevel] = { level: mappedLevel, pct: 0 };
    }
    result[mappedLevel].pct += opt.pct;
  });
  
  return Object.values(result);
};
```

## 6. 常见问题 FAQ

### Q1: schema_version字段如何使用？
**A**: `schema_version` 用于标识数据格式版本，当前固定为 "v1.2"。前端可以根据此字段判断数据格式：

```javascript
const processData = (responseData) => {
  const { schema_version, subjects } = responseData;
  
  if (schema_version === 'v1.2') {
    // 使用新的统一 subjects 结构
    return subjects;
  } else {
    // 兼容旧版本格式
    console.warn('不支持的数据版本:', schema_version);
    return [];
  }
};
```

### Q2: 数值精度如何处理？
**A**: 所有数值统一保留两位小数，百分比范围为 0-100：

```javascript
// 显示格式化
const formatScore = (score) => {
  return typeof score === 'number' ? score.toFixed(2) : '--';
};

const formatPercentage = (pct) => {
  return typeof pct === 'number' ? `${pct.toFixed(2)}%` : '--';
};

// 数值比较时注意精度
const compareScores = (score1, score2) => {
  return Math.abs(score1 - score2) < 0.01; // 容差比较
};
```

### Q6: API超时如何处理？
**A**: 设置合理的超时和重试机制：

```javascript
// 带超时和重试的请求
const fetchWithRetry = async (url, options = {}, maxRetries = 3) => {
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), 30000); // 30秒超时
  
  for (let retry = 0; retry <= maxRetries; retry++) {
    try {
      const response = await fetch(url, {
        ...options,
        signal: controller.signal
      });
      
      clearTimeout(timeoutId);
      return response;
      
    } catch (error) {
      if (retry === maxRetries) {
        throw new Error(`请求失败，已重试${maxRetries}次: ${error.message}`);
      }
      
      // 等待后重试
      await new Promise(resolve => setTimeout(resolve, 1000 * (retry + 1)));
    }
  }
};
```

```javascript
import React, { useState, useEffect } from 'react';
import { Card, Spin, Alert, Tabs, Row, Col, Table, Statistic } from 'antd';

const StatisticsPage = ({ batchCode, schoolCode }) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

          setData(result.data);

        setLoading(false);
      }
    };

  if (loading) return <Spin size="large" />;
```
