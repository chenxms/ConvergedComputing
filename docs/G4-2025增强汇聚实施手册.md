# 全批次强制增强汇聚实施手册

## 1. 目标与范围
- 本轮要求所有批次（含历史与新增）在清洗→区域汇聚→学校汇聚全流程中统一执行强制增强逻辑。
- 输出的 subjects 结构必须包含增强字段：百分位 (P10/P50/P90)、区分度、等级分布、得分率/学生数、问卷题目与维度选项占比等。
- 不再保留旧版 fallback，任一阶段缺失增强数据即终止并抛出错误。

## 2. 环境与依赖
1. 推荐命令示例：`python run_full_batch_pipeline.py <批次编码>`（如 G4-2025、G8-2025 等）
2. 关键代码位置：
   - `app/services/calculation_service.py`
   - `app/services/subjects_builder.py`
   - `data_cleaning_service.py`
   - `app/database/connection.py`, `app/database/repositories.py`
3. 预聚合表：`subject_core_metrics`, `subject_school_rankings`（清洗阶段写入）。
4. 缓存/连接：Redis 缓存正常，SQLAlchemy Session 已设置 `expire_on_commit=False`，支持长事务重用。

## 3. 当前状态概览（2025-09-18 04:55，基于近期批次观察）
- 清洗阶段：成功落库科目核心指标与学校排名，校验表存在。
- 汇聚运行：清洗与区域 subject 构建成功，但写入 `statistical_aggregations` 区域记录时多次遭遇 MySQL 1205/2013，定位为外部锁占用。
- 功能缺口：
  1. 区域/学校 subjects 未携带增强指标（p10/p50/p90、区分度、等级分布、学生数、得分率等）。
  2. 学校排名 (`school_rankings`) 仅含平均分和排名，缺失得分率/学生数等列。
  3. 问卷科目未输出题目选项占比 (`questions`)，仅保留维度聚合。
  4. 校验逻辑待补充，无法检测新增字段缺失。

## 4. 待办拆解
### 4.1 数据库锁排查（需DBA配合）
- 检查 `statistical_aggregations` 对目标批次的未提交事务或长时间锁。
- 在低峰时段释放/kill 持锁连接后再执行跑批，确认 UPSERT 正常。

### 4.2 SubjectsBuilder 增强补齐
- `_compute_subject_metrics`：补写 `student_count`、`score_rate`、`pass_rate`、`excellent_rate`、`good_rate`、`fail_rate`、`difficulty`、`percentiles`、`discrimination`、`grade_distribution` 等字段；兼容考试/问卷。
- `_compute_school_rankings`：扩展输出 `score_rate`、`student_count`、`difficulty`、`max/min`。
- `_compute_questionnaire_question_option_distribution`：恢复题目选项占比，注入 `subjects[].questions` 或 `subjects[].question_option_distribution`。
- `_validate_enhanced_subjects`：新增校验项，确保上述字段存在且非空。

### 4.3 CalculationService 对接
- 确认 `_consolidate_multi_subject_results` 产出的 `statistics_data` 包含课程指标、等级分布、问卷题目占比；若缺失，补充生成逻辑。
- `_save_regional_statistics` / `_save_school_statistics`：引入失败重试日志，并在回写前打印关键字段。

### 4.4 回归测试
- 新增/更新 `tests/test_subjects_builder_enhanced.py`、`tests/test_statistical_metrics_integration.py` 覆盖增强字段。
- 手动执行 `python run_full_batch_pipeline.py G4-2025`，记录运行耗时与日志。
- 检查 `statistical_aggregations` 中 `statistics_data` JSON，确认增强字段齐全。

## 6. 验收标准
- 区域/学校 subjects 满足增强字段清单，无字段缺失或为 `null`/空列表。
- `school_rankings` 至少包含：`school_id`、`school_name`、`avg`、`score_rate`、`rank`、`student_count`。
- 问卷科目具备维度占比与题目占比，两端数据一致。
- `statistical_aggregations` 写入成功，无 1205/2013 错误，UPSERT 重试次数≤1。
- 运行总耗时控制在 20 分钟内。

## 7. 常见问题 & 处理
| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 1205 Lock wait timeout | 其他会话未提交、`statistical_aggregations` 长事务 | 查 kill 连接，重新执行 |
| 区域/学校缺增强字段 | SubjectsBuilder 未读取 enhanced_stats 或字段拼装遗漏 | 回归 `_compute_subject_metrics`、`_validate_enhanced_subjects` |
| 问卷题目无占比 | 未调用 `_compute_questionnaire_question_option_distribution` 或数据缺失 | 恢复函数/补写 SQL，检查 `questionnaire_option_distribution` |
| 材料库缺记录 | 清洗落库失败或批次未清空旧数据 | 查看 `data_cleaning_service._materialize_precomputed_metrics` 日志 |
