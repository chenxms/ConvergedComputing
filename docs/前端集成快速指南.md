
### 步骤2: 创建API客户端
```javascript
// 从示例代码复制 ApiClient 类
import { ApiClient } from './utils/api-client';

const apiClient = new ApiClient('http://your-api-domain:8000');
```

### 步骤3: 基础用法
```javascript
// 获取区域数据
const regionalData = await apiClient.getRegionalData('G4-2025');

// 获取学校数据

// 渲染数据
const examSubjects = regionalData.subjects.filter(s => s.type === 'exam');
console.log(`找到 ${examSubjects.length} 个考试科目`);
```

## 📊 核心数据结构

### 区域层数据
```typescript
interface RegionalData {
  schema_version: "v1.2";
  batch_code: string;
  aggregation_level: "REGIONAL";
  subjects: Subject[];  // 包含学校排名
}
```

### 学校层数据
```typescript
interface SchoolData {
  schema_version: "v1.2"; 
  batch_code: string;
  aggregation_level: "SCHOOL";
  school_code: string;
  subjects: Subject[];  // 包含区域排名
}
```

### 科目结构
```typescript
type Subject = ExamSubject | QuestionnaireSubject;

// 考试科目
interface ExamSubject {
  type: "exam";
  subject_name: string;
  metrics: { avg, stddev, max, min, difficulty };
  dimensions: ExamDimension[];
  
  // 区域层: 包含学校排名
  school_rankings?: SchoolRanking[];
  
  // 学校层: 包含该校排名
  region_rank?: number;
  total_schools?: number;
}

// 问卷科目
interface QuestionnaireSubject {
  type: "questionnaire";
  subject_name: string;
  metrics: { avg, stddev, max, min, difficulty };
  dimensions: QuestionnaireDimension[];  // 包含 option_distribution
  questions?: QuestionData[];            // 题目级分布
  
  // 排名信息同考试科目
}
```

## 🎯 常见使用场景

### 场景1: 区域教育局看整体
```javascript
const data = await apiClient.getRegionalData('G4-2025');

// 显示所有学校排名
data.subjects.forEach(subject => {
```


### 场景3: 问卷满意度分析
```javascript
const questionnaireSubjects = data.subjects.filter(s => s.type === 'questionnaire');

questionnaireSubjects.forEach(subject => {
  subject.dimensions.forEach(dimension => {
    if (dimension.option_distribution) {
      const summary = calculateSatisfactionSummary(dimension.option_distribution);
      console.log(`${dimension.name} 满意度: ${summary.satisfied.toFixed(1)}%`);
    }
  });
});
```

## ⚠️ 注意事项

### 1. 数据精度
所有数值统一保留2位小数，前端显示时使用 `.toFixed(2)`

### 2. 中文编码
确保API请求头包含 `charset=utf-8`

### 3. 错误处理
```javascript
try {
  const data = await apiClient.getRegionalData(batchCode);
} catch (error) {
  if (error.message.includes('404')) {
    showError('批次不存在，请检查批次代码');
  } else if (error.message.includes('timeout')) {
    showError('请求超时，请稍后重试');
  } else {
    showError(`请求失败: ${error.message}`);
  }
}
```

### 4. 性能优化
- 大量学校排名使用虚拟滚动
- 图表容器设置合适的高度
- 适当使用缓存避免重复请求
