1.2 学校科目 metrics 中增加 rank、百分位、区分度、等级比例四档
- 位置：`build_school_subjects`
- 现状：
  - `rank` 以 `region_rank` 形式在 subject 顶层；
  - `p10/p50/p90`、`discrimination`、`grade_distribution` 注入在 subject 顶层或 metrics.percentiles 内；
- 目标：全部进入 `metrics`：
  - `metrics.rank = region_rank.region_rank`
  - `metrics.p10/p50/p90`
  - `metrics.discrimination`
  - `metrics.rate_excellent/rate_good/rate_pass/rate_fail`（百分比 0–100）
- 精确修改：
  - 在构建 `subj` 前后，插入：
    ```python
    metrics = self._compute_subject_metrics(..., enhanced_stats=subject_enhanced_stats)
    # 1) 学校排名并入 metrics
    rr = self._compute_school_region_rank(batch_code, s.name, school_code)
    metrics['rank'] = int(rr.get('region_rank')) if rr and rr.get('region_rank') else None
    # 可选：保留总校数到 metrics 便于校验
    if 'total_schools' in rr:
        metrics['total_schools'] = int(rr['total_schools'])

    # 2) 百分位、区分度：从 enhanced_stats 扁平化到 metrics
    if subject_enhanced_stats:
        p = subject_enhanced_stats.get('percentiles', {})
        if p:
            metrics['p10'] = round2(p.get('P10', 0))
            metrics['p50'] = round2(p.get('P50', 0))
            metrics['p90'] = round2(p.get('P90', 0))
        disc = subject_enhanced_stats.get('discrimination')
        if isinstance(disc, dict) and 'discrimination_index' in disc:
            metrics['discrimination'] = round2(disc['discrimination_index'])
        elif isinstance(disc, (int, float)):
            metrics['discrimination'] = round2(disc)

        # 3) 等级比例：四档 0–100
        gd = subject_enhanced_stats.get('grade_distribution') or {}
        # 小学/初中两种结构兼容
        metrics['rate_excellent'] = round2((gd.get('excellent', {}) or {}).get('percentage', 0) * 100) if 'excellent' in gd else round2(gd.get('a_rate', 0) * 100)
        metrics['rate_good'] = round2((gd.get('good', {}) or {}).get('percentage', 0) * 100) if 'good' in gd else round2(gd.get('b_rate', 0) * 100)
        metrics['rate_pass'] = round2((gd.get('pass', {}) or {}).get('percentage', 0) * 100) if 'pass' in gd else round2(gd.get('c_rate', 0) * 100)
        metrics['rate_fail'] = round2((gd.get('fail', {}) or {}).get('percentage', 0) * 100) if 'fail' in gd else round2(gd.get('d_rate', 0) * 100)
    ```
  - 构建 `subj` 时：
    - 删除 subject 顶层的 `**region_rank` 注入与 `p10/p50/p90/discrimination/grade_distribution` 顶层写入；
    - 改为：
      ```python
      subj = {
          'subject_name': s.name,
          'type': s.type,
          'metrics': round2_json(metrics)
      }
      ```

## 3. SQL 片段校准（排名与分位）

3.1 学科排名（学校级，跨校）：
```sql
WITH subj_school AS (
  SELECT scs.school_code,
         ROUND(AVG(scs.total_score), 2) AS avg
  FROM student_cleaned_scores scs
  JOIN school_master_data smd
    ON smd.batch_code = scs.batch_code AND smd.school_id = scs.school_code AND smd.status='ACTIVE'
  WHERE scs.batch_code=:batch AND scs.subject_name=:subject AND scs.subject_type IN ('exam','questionnaire')
  GROUP BY scs.school_code
)
SELECT school_code,
       DENSE_RANK() OVER (ORDER BY avg DESC, school_code ASC) AS rank
FROM subj_school;
```

3.2 维度排名（学校级，跨校，同维度）：
- 已在 `_compute_school_dimensions_with_rank` 实现；确认 JSON 路径与回退问卷明细 SQL 都限定 `subject_name=:subject` 且 JOIN ACTIVE 学校。

3.3 百分位（学校级，学科内）：
- 由计算引擎完成；如需 SQL：
```sql
SELECT 
  PERCENTILE_CONT(0.1) WITHIN GROUP (ORDER BY total_score) AS p10,
  PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY total_score) AS p50,
  PERCENTILE_CONT(0.9) WITHIN GROUP (ORDER BY total_score) AS p90
FROM student_cleaned_scores
WHERE batch_code=:batch AND subject_name=:subject AND school_code=:school;
```

## 5. 回归用例（关键断言）

- rank 类型与范围：所有 rank 为整数，且 1..total_schools；不出现 1.0。
- 百分位落位：学校级 percentiles 与本校学生分布一致；不同学校间值可不同。
- 等级比例：四档合计=100%（±0.01 容差）。
- 问卷 metrics：仅含 avg/score_rate/rank（不含 stddev/difficulty 等考试专属字段）。
- 维度输出：仅 code/name/avg/score_rate/rank；不含 regional_avg 与问卷分布结构。
