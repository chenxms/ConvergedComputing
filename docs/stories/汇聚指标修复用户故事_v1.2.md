## 一、背景与问题

现网 v1.2 汇聚输出存在以下偏差：
- 缺失必需指标：学科层缺少区分度、P10/P50/P90、等级比例等；维度/问卷缺少所需指标；题目选项分布未标准化。
- 排名异常：维度/问卷/学科排名字段出现全为 1.0（浮点）等错误。
- 口径混乱：学校页增强统计误用区域口径；输出混入非定义字段（如学科级 regional_avg 等）。
- 结构不稳：一题多维度时被错误地强扯与学科口径耦合。

本故事旨在：恢复并锁定“清洗→汇聚”的两段式流程；清退未定义字段；补齐并统一必需指标；修复排名；一次验收通过。

## 二、目标与范围

- 目标：
  - 按 v1.2 规范，补齐并统一所有指标的计算口径与输出结构。
  - 排名在全量学校数据上计算，输出学校视图时仅取本校值，类型为整数。
  - 题目选项分布以独立聚合表提供，不嵌入学科 JSON（仅保留学科/维度统计）。
- 范围：考试类学科、问卷类学科、维度统计、题目选项分布、API v1.2 输出。
- 非范围：题库/维度映射规则调整、报表样式/UI 变更、算法外延优化。

## 三、术语与统一口径

- 学科总分 subject_full_score：来自配置（与维度满分和无强关系）。
- 难度 difficulty：学校内学生学科总分的平均分 / subject_full_score，结果区间 [0,1]，保留 2 位小数。
- 区分度 discrimination（学科层）：Kelley 27% 法：
  - 将学校内学生按该学科总分降序分为 Top27% 与 Bottom27%。
  - 计算两组均分之差，除以 subject_full_score，得到区间 [0,1]，保留 4 位小数（存储），展示 2 位。
  - 当样本量 < 30 时回退 Top/Bottom 25%；当样本量 < 12 时输出 null。
- 百分位：P10/P50/P90 使用连续分位 `PERCENTILE_CONT(0.1/0.5/0.9)`。
- 等级比例：依据学科阈值配置，将学校内学生按优秀/良好/及格/不及格分档；四档合计 100%。
  - 边界（建议）：区间左闭右开，最高档右闭；示例：[优秀_min, +∞] 右闭。
  - 展示按百分比 0–100，2 位小数；存储可留 4 位小数并使用“最大余数法”校正到 100%。
- 得分率 score_rate（维度/问卷）：avg/max_score 或 avg/subject_full_score，按百分比 0–100 输出，2 位小数。
- 排名 rank：
  - 学科排名：跨校（同批次、同学科）按学科平均分降序 RANK()；类型 int。
  - 维度排名：跨校（同批次、同学科、同维度）按维度平均分降序 RANK()；类型 int。
  - 问卷排名：跨校（同批次、同问卷学科）按平均分降序 RANK()；类型 int。
- 一题多维度：维度与学科口径互不强耦；各自独立计算与排名。

## 四、流程与数据源

- 清洗层（保持不变）：去重/去无效、异常值处理、缺失策略、题目→维度映射校验、学生与学校主数据联通。
- 汇聚层（修复要点）：
  1) 先在“全体学校样本集”计算排名与区域统计；
  2) 学校视图仅按 `school_id` 回取该校记录；
  3) 学校页增强统计（百分位、区分度、等级比例）严格使用“该校学生样本”。
- 配置表：
  - subject_full_score、维度满分、等级阈值、问卷计分规则、题目→维度映射；均为必填。

## 四点承诺（避免反复）

- 统一输出口径：以本故事为唯一规范，输出字段实行白名单制；凡不在白名单的，一律不出。
- 单一排名口径：跨校（ACTIVE 学校）集合上计算，再回取本校；rank 一律整数。
- 学校增强口径：百分位、区分度、等级比例，均以“该校学生样本”计算，不得引用区域数据。
- 题目分布隔离：题目选项分布独立表与接口，不再嵌入 subjects，防止上下游耦合与膨胀。

## 五、输出字段白名单（v1.2 最终）

### 5.1 学科-考试（每学科×每校）
- metrics：
  - avg: number（均分）
  - rank: int（学校在区域内该学科排名）
  - stddev: number（标准差，建议总体标准差）
  - difficulty: number ∈ [0,1]（难度）
  - discrimination: number ∈ [0,1] 或 null（区分度）
  - p10/p50/p90: number（分位数）
  - max/min: number（最高/最低分）
  - rate_excellent/rate_good/rate_pass/rate_fail: number（百分比 0–100，2dp）
- 额外：subject_full_score: number（回显校验用，可选但推荐）

### 5.2 学科-问卷（每学科×每校）
- metrics：
  - avg: number
  - score_rate: number（百分比 0–100，2dp）
  - rank: int

### 5.3 维度（每维度×每校）
- fields：
  - code: string
  - name: string
  - avg: number
  - score_rate: number（百分比 0–100，2dp）
  - rank: int

### 5.4 题目选项分布（独立表，不嵌入 subjects）
- 表名建议：`qn_question_option_distribution`
- 字段：`batch_code, school_id, subject_name, question_id, option_level, option_label, count, n_total, pct`（pct 百分比 0–100，4dp 存储，2dp 展示）

- 清退字段：所有未在以上白名单中的字段（如学科级 regional_avg、浮点型 rank 1.0 等）一律不输出。

## 六、计算规则与示例 SQL（参考 PostgreSQL 语法）

> DEV 可据数据库类型等价替换函数。以下仅示意关键口径。

- 学科（考试）学校级统计：
```sql
WITH s AS (
  SELECT student_id, total_score
  FROM school_subject_student_scores
  WHERE batch_code=:batch AND subject_name=:subject AND school_id=:school
)
, base AS (
  SELECT
    AVG(total_score) AS avg,
    STDDEV_POP(total_score) AS stddev,
    PERCENTILE_CONT(0.1) WITHIN GROUP (ORDER BY total_score) AS p10,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY total_score) AS p50,
    PERCENTILE_CONT(0.9) WITHIN GROUP (ORDER BY total_score) AS p90,
    MAX(total_score) AS max,
    MIN(total_score) AS min,
    COUNT(*) AS n
  FROM s
)
, parted AS (
  SELECT total_score,
         NTILE(100) OVER (ORDER BY total_score DESC) AS tile,
         COUNT(*) OVER() AS n
  FROM s
)
, discr AS (
  SELECT
    CASE WHEN (SELECT n FROM base) < 12 THEN NULL
         ELSE (
           (SELECT AVG(total_score) FROM parted WHERE tile <= 27) -
           (SELECT AVG(total_score) FROM parted WHERE tile > 73)
         ) / :subject_full_score
    END AS discrimination
)
SELECT
  b.avg,
  b.stddev,
  b.p10, b.p50, b.p90,
  b.max, b.min,
  ROUND(b.avg / :subject_full_score, 2) AS difficulty,
  d.discrimination
FROM base b CROSS JOIN discr d;
```

- 等级比例（以阈值示例实现）：
```sql
SELECT
  100.0 * AVG(CASE WHEN total_score >= :excellent_min THEN 1 ELSE 0 END) AS rate_excellent,
  100.0 * AVG(CASE WHEN total_score >= :good_min AND total_score < :excellent_min THEN 1 ELSE 0 END) AS rate_good,
  100.0 * AVG(CASE WHEN total_score >= :pass_min AND total_score < :good_min THEN 1 ELSE 0 END) AS rate_pass,
  100.0 * AVG(CASE WHEN total_score < :pass_min THEN 1 ELSE 0 END) AS rate_fail
FROM s;
```

- 学科排名（跨校）：
```sql
WITH subj_school AS (
  SELECT batch_code, subject_name, school_id, AVG(total_score) AS avg
  FROM school_subject_student_scores
  WHERE batch_code=:batch AND subject_name=:subject
  GROUP BY 1,2,3
)
SELECT school_id,
       RANK() OVER (PARTITION BY batch_code, subject_name ORDER BY avg DESC) AS rank
FROM subj_school;
```

- 维度统计与排名（独立于学科分）：
```sql
WITH dim_scores AS (
  SELECT school_id, student_id, dimension_code, dimension_score, dimension_full_score
  FROM school_subject_dimension_scores
  WHERE batch_code=:batch AND subject_name=:subject
)
, dim_school AS (
  SELECT batch_code, subject_name, school_id, dimension_code,
         AVG(dimension_score) AS avg,
         100.0 * AVG(dimension_score / NULLIF(dimension_full_score,0)) AS score_rate
  FROM dim_scores
  GROUP BY 1,2,3,4
)
SELECT *,
  RANK() OVER (
    PARTITION BY batch_code, subject_name, dimension_code
    ORDER BY avg DESC
  ) AS rank
FROM dim_school;
```

- 问卷（学科级）与排名：
```sql
WITH qn_school AS (
  SELECT batch_code, subject_name, school_id,
         AVG(total_score) AS avg,
         100.0 * AVG(total_score / NULLIF(:subject_full_score,0)) AS score_rate
  FROM questionnaire_student_scores
  WHERE batch_code=:batch AND subject_name=:subject
  GROUP BY 1,2,3
)
SELECT *,
  RANK() OVER (PARTITION BY batch_code, subject_name ORDER BY avg DESC) AS rank
FROM qn_school;
```

- 题目选项分布（独立表）：
```sql
INSERT INTO qn_question_option_distribution (
  batch_code, school_id, subject_name, question_id,
  option_level, option_label, count, n_total, pct
)
SELECT
  :batch, :school, :subject, q.question_id,
  q.option_level, q.option_label,
  COUNT(*) AS count,
  SUM(COUNT(*)) OVER (PARTITION BY q.question_id) AS n_total,
  100.0 * COUNT(*) / NULLIF(SUM(COUNT(*)) OVER (PARTITION BY q.question_id), 0) AS pct
FROM questionnaire_answers q
WHERE q.batch_code=:batch AND q.school_id=:school AND q.subject_name=:subject
GROUP BY q.question_id, q.option_level, q.option_label;
```

## 八、实施任务清单（DEV）

1) 输出白名单与结构收敛
- 移除所有未定义字段；rank 一律整数；百分比字段 0–100（2dp）。
- 增加学科层缺失指标：`discrimination, p10, p50, p90, rate_*`。
- 补充 `subject_full_score`（仅为校验与可溯源）。

2) 计算修复
- 学校页增强统计改用学校样本（而非区域样本）。
- 排名在“全校集合”计算，学校视图仅回取本校；同批次、同学科（或同维度）。

3) 维度/问卷
- 维度与学科独立计算，严禁按题目映射去强扯“维度分之和=学科分”。
- 问卷仅需 avg、score_rate、rank；不输出 stddev 等未定义字段。

4) 题目选项分布
- 以独立表 `qn_question_option_distribution` 存储；提供学校级查询接口；按科目过滤。

5) 参数与精度
- 所有展示保留 2 位小数；内部计算保留 4 位；百分比合计采用“最大余数法”校正至 100%。

## 九、验收标准（Given-When-Then）

- Given 同批次 56 所学校、数学科目 When 计算排名 Then `rank` 为 1..56 的整数且分布合理；不出现 1.0。
- Given 学科满分=100、平均分=84.62 When 计算难度 Then `difficulty=0.85±0.01`。
- Given 学生成绩分布 When 计算 P10/P50/P90 Then 与 `PERCENTILE_CONT` 一致（误差≤1e-6）。
- Given 样本量≥30 When 计算区分度 Then 使用 27% 分位区间两均值差/满分；样本量<12 输出 null。
- Given 阈值配置 When 计算等级比例 Then 四档之和=100%（±0.01 容差），边界落档符合定义。
- Given 问卷数据 When 输出学校级问卷 Then 仅包含 avg、score_rate、rank；维度同口径。
- Given 一题多维度 When 产出维度统计 Then 不强制与学科总分对齐，互不影响。
- Given 学校页与区域页 When 对比增强统计 Then 学校页的百分位/等级分布随校而异（口径独立），非简单复制区域。
