# Story 01.01: v1.2 汇聚流程缺陷修复（正式故事）

## Status
Ready for Review

## Story
作为报表与接口使用方，我希望修复 v1.2 汇聚流程中的关键缺陷（问卷分布需按科目纯净、学校页增强统计需使用学校级口径、ACTIVE 学校口径一致、维度集合完整、精度统一），以便区域与学校数据口径一致、结果稳定，能直接用于前端与报告。

## 字段与类型约定
- 学校标识统一为 `school_id`（如历史描述中出现 `school_code`，均以 `school_id` 为准）。
- 科目类型仅两类：`exam` 与 `questionnaire`；`interaction` 科目按考试路径计算，并在输出中以 `type='exam'` 表示（类型映射：interaction → exam）。

## Acceptance Criteria
1. 问卷维度/题目选项分布仅包含本科目数据（P0）
   - REGIONAL：`subjects[].dimensions[].questions[].option_distribution[]`、`subjects[].dimensions[].option_distribution[]`、`subjects[].questions[]` 均仅来源于 `subject_name = 当前科目` 的 `questionnaire_option_distribution`/`question_dimension_mapping` 统计。
   - SQL 断言：对每个问卷科目 S，`JOIN question_dimension_mapping(qdm subject=S)` 与 `questionnaire_option_distribution(qqd subject!=S)` 的交集数量为 0。
2. 学校页增强统计来自学校级数据（P0）
   - SCHOOL：每个科目 `p10/p50/p90/discrimination/grade_distribution` 源自该校数据。与区域级允许不同（不强求一致）。
3. 仅输出 exam / questionnaire（P1）
   - `subjects[].type ∈ {exam, questionnaire}`，不包含 `interaction`。
4. 区域维度均分与 ACTIVE 学校口径对齐（P1）
   - 区域维度均分统计限定在 `school_master_data.status = 'ACTIVE'` 学校集合，与 `school_rankings` / `total_schools` 口径一致。
5. 维度集合优先来源 BDD（P1）
   - 维度代码优先来源 `batch_dimension_definition`（BDD）；若 BDD 不全，再回退 JSON 探测，确保与配置一致。
6. 精度统一（保底）
   - 所有数值两位小数；百分比字段（`*_pct/*_rate/*_percentage/pct`）为 0–100 且两位小数。
7. 排名产出完整（保底）
   - REGIONAL：`subjects[].school_rankings` 存在且排序为 avg 降序、同分按 `school_id` 升序（DENSE_RANK）；项包含 `{ school_id, school_name, avg, rank }`。
   - SCHOOL：`subjects[].region_rank` 与 `subjects[].total_schools` 存在且取值正确。

## Dev Notes
- 代码触点与口径
  - REGIONAL 学校排名/我校名次/维度均分口径均基于 ACTIVE 学校集（表：`school_master_data`）。
  - 问卷分布：
    - 维度聚合：`questionnaire_option_distribution` + `question_dimension_mapping`；严格限定 `batch_code`、`subject_name` 双侧；按 `option_level` 聚合为 `pct`。
    - 题目分布：`questionnaire_option_distribution`（按题目）或学校级走 `questionnaire_question_scores`。
  - 标签映射：`_get_scale_label_map` 先取出现频次最高的 `(instrument_type, scale_level)`；如多量表共存，记录 WARN 日志（短期不阻断）。
  - 维度集合：优先 `batch_dimension_definition`，`dimension_max_score` 可用于得分率；缺失回退 JSON。
  - 精度：统一使用 `app/utils/precision.py::round2_json`；百分比 0–100。
- 重要 SQL 篇章（伪）：
  - 维度-题目分布（新增过滤）：`... WHERE qqd.batch_code=:batch AND qqd.subject_name=:subject AND qdm.subject_name=:subject ...`
  - 学校级维度/排名：使用 `student_cleaned_scores.dimension_scores` JSON 抽取 + DENSE_RANK（同分并列）。
- 兼容性：暂不输出 `interaction` 科目，避免下游 SQL 口径不一致。
